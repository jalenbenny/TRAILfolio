Hybrid retrieval and LLM verification system for open-source schema-guided clinical information extraction of synthetic nursing transcripts. Built as the Lakefront AI Ramblers entry to the MEDIQA-SYNUR 2026 shared task, combining lexical and dense retrieval with an LLM verification stage on an open-source model.

**Data availability:** Task data is distributed by the shared task organizers and not redistributed here. Code and config only.
