Applies NLP to free-text EMS run narratives to detect which assessment findings were actually collected and recorded on scene/in the ambulance. The extracted narrative content is intended to supplement the structured EMS fields used by the triage models, giving a text+tabular view of the same encounter.

**Data availability:** Uses the same restricted EMS dataset. Narratives contain PHI and are never committed. Repo holds code, annotation, and aggregate results only.
