## Synopsis
Wraps standard ML interpretability outputs, such as SHAP feature attributions and counterfactuals, with an LLM layer that converts them into clear, clinician-facing plain-language explanations.

## Data Availability
Uses the same restricted clinical datasets as the underlying prediction models. Repo holds pipeline code and prompt templates.
