## Synopsis
In LUMC EHR data, a true pre-admission baseline serum creatinine is missing for many patients, so back-estimation methods are commonly substituted; this analysis stages AKI under both methods for comparison.

## Data Availability
LUMC (Loyola University Medical Center) EHR data is restricted under IRB and contains PHI; not shared. Repo holds code and documentation.
