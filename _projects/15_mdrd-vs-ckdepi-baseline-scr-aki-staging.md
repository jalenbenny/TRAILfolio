In LUMC EHR data, a true pre-admission baseline serum creatinine is missing for many patients, so back-estimation methods are commonly substituted. This analysis compares how staging outcomes differ by method.

**Data availability:** LUMC (Loyola University Medical Center) EHR data is restricted under IRB and contains PHI; not shared. Repo holds analysis code only.
