Implements a posteriori Bayesian estimation on the log scale, using published population priors, to calculate individualized two-compartment vancomycin AUC24 values.

**Data availability:** Validation cohorts include PHI-restricted clinical data not shared in the repo. Repo holds the engine code and documentation.
