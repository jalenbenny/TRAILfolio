This project uses an LLM to evaluate the medical content of the Caroli Disease and Syndrome Ontology (CaroliO). Explicit ontology axioms and class relationships are checked against biomedical literature.

**Data availability:** Uses the Basic CaroliO OWL ontology and published PubMed literature. No patient-level data or protected health information involved.
